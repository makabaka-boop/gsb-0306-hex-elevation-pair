# 六角视线（Hex LOS）

离线六角棋盘视线演示：Vue 3 + TypeScript + SVG 前端，Docker Compose 托管静态页面。
所有几何判定在整数 / 有理数上精确完成，不做屏幕像素采样，可见性不随缩放改变。

## 几何模型

棋盘支持高度视线：观察点与目标点的眼高分别为 `observerEye`、`targetEye`（0～8 的整数），每个阻挡格为从地面到其独立高度（0～8）的竖直柱体。视线高度沿两格心连线线性变化；只有视线在阻挡六边形的严格内部且严格低于柱顶时才遮挡，恰好触顶或只碰边界不遮挡。格子高度 0 不遮挡。命中列表与最先遮挡位置按真实高度交点给出，使用精确有理数；画布和列表展示同一结果。切换阻挡格、移动观察点和缩小棋盘后，高度设置应与实际阻挡格一致。

- 轴坐标 `(q, r)`，整数平面嵌入：格心 `(2q + r, 3r)`；
  顶点相对格心依次为 `(0,2) (1,1) (1,-1) (0,-2) (-1,-1) (-1,1)`。
- 观察点格心到目标格心的**开线段**，只有穿过阻挡六边形的**严格内部**才算被遮挡；
  擦角、沿边等纯边界接触一律不算。
- 判定对每个六边形维护开区间 `(lo, hi)`：六条边的半平面逐个裁剪，
  区间非空（`lo < hi`，严格）才算遮挡；交入参数 `t = lo` 与交入位置均为有理数（bigint 分数）。
- 选中目标时报告**最先遮挡格**及有理交入位置；并列按 **交入位置 t → q → r** 裁决。
- 目标格本身是阻挡格时，开线段仍穿过其内部，按字面语义判为不可见。
- 画布与列表共用同一份 `computeBoard` 结果（`src/geometry/visibility.ts`）。

## 界面

- 半径 2～12 的轴坐标棋盘，可编辑阻挡格与一个观察点（模式：目标 / 阻挡 / 观察点）。
- 画布标出全部可见格；选中目标显示视线、最先遮挡格与交入点；右侧列表与画布共享几何结果。
- 滚轮 / 按钮缩放只改变 SVG 变换，不影响几何结论。

## 开发

```bash
npm install
npm run dev        # 本地开发
npm test           # Vitest：擦角 / 沿边 / 两障碍同距 / 缩放不变性 + 独立有理裁剪对拍
npm run typecheck  # vue-tsc 类型检查
npm run build      # 产出 dist/
```

## Docker

```bash
docker compose up --build   # http://localhost:8080
```

多阶段构建：`node:22-alpine` 内 `npm ci && npm run build`，产物由 `nginx:alpine` 托管。

## 测试

`tests/visibility.spec.ts` 覆盖：

- **擦角**：视线恰过障碍顶点（如 `(0,0)→(5,2)` 擦过 `(2,0)` 的顶点 `(4,2)`）不遮挡；
  偏移后遮挡并给出精确交入位置（`(3, 9/11)`，`t=3/11`）。
- **沿边**：视线沿两格共享边前进不遮挡。
- **两障碍同距**：视线穿过两障碍的共同顶点，只有进入内部的那一格计入；
  另有并列裁决（t、q、r）与排序确定性用例。
- **缩放不变性**：嵌入放大 2/3/7/1000 倍，可见性、最先遮挡与交入参数完全一致。
- **对拍**：半径 2 小棋盘上，与 `tests/independent.ts`
  （独立的“临界参数 + 中点采样”有理线段裁剪，自带分数运算）全量比对
  单阻挡、全部阻挡对以及 seeded 随机阻挡集。
